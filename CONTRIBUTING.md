# 🤝 Contributing to HybridRAG

First off, thank you for considering contributing to HybridRAG! It's people like you that make the open-source community such an amazing place to learn, inspire, and create.

## 🌈 Code of Conduct
Please be respectful and inclusive in all interactions.

## 🚀 How to Contribute

### 1. Report Bugs
Use the GitHub issue tracker to report bugs. Include:
- Steps to reproduce.
- Expected vs. Actual behavior.
- Environment details (OS, Python/Node versions).

### 2. Suggest Enhancements
We love new ideas! Please open an issue first to discuss large changes.

### 3. Pull Requests
1.  **Fork** the repo and create your branch from `main`.
2.  **Add tests** for any new features or bug fixes.
3.  **Ensure CI passes** (linting, tests).
4.  **Update documentation** if your change affects usage.
5.  **Submit** the PR with a clear description of the "Why" and "How".

---

## 🎨 Style Guidelines

### Python
- Follow **PEP 8**.
- Use **type hints** for all function signatures.
- Document classes and public methods with docstrings.

### React / Frontend
- Use functional components and hooks.
- Follow the established **Vanilla CSS / Glassmorphism** patterns.
- Ensure accessibility (a11y) for interactive elements.
